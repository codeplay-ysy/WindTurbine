# 毕设项目：基于改进 YOLOv8 的风电叶片缺陷检测系统

本项目用于构建一个面向风电叶片缺陷检测的前后端推理系统，适合作为本科毕业设计的工程化展示平台。

## 项目结构

- `backend/`：后端服务，负责加载模型、接收图片、执行推理、返回检测结果
- `frontend/`：前端页面，负责图片上传、结果展示、系统介绍
- `models/`：存放训练好的模型权重文件（如你的 `best.pth`）

## 推荐做法

由于你当前持有的是 `pth` 文件，后续需要先确认：

1. 该 `pth` 是完整模型还是 `state_dict`
2. 当前改进后的 YOLOv8 代码是否需要自定义模块才能正常加载
3. 是否能导出为更适合部署的格式，例如 `pt` / `onnx`

目前我已经先为你搭建了项目骨架，后续你只需要：

- 把模型权重放到 `models/`
- 在后端补充真实的模型加载逻辑
- 启动前后端后即可进行联调

## 启动方式

### 1. 后端

进入 `backend/` 后安装依赖：

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 前端

进入 `frontend/` 后安装依赖：

```bash
npm install
npm run dev
```
